Составлены аудитом `improve-animations` от коммита `baf3209`, ветка `animations-polish`.

## Порядок выполнения

Строго последовательный — все четыре плана правят `app/globals.css`, параллельное
выполнение даст конфликты.

```
001 ──┬── 002 ── 003
      └── 004
```

- **001 идёт первым всегда.** Он вводит токены `--duration-fast` / `--duration-base` /
  `--duration-slow`, на которые ссылаются остальные три. Сам по себе визуально не меняет
  ничего — это подготовка.
- **002 после 001.** Использует токены; добавляет состояния `:active`.
- **003 после 002.** Его блок reduced-motion гасит `transform` у состояний `:active`,
  которые появляются только в 002.
- **004 после 001**, от 002 и 003 не зависит, но выполняется последним, чтобы не
  конфликтовать с ними по файлу.

## Общий контекст

Причина, по которой три из четырёх планов помечены HIGH: в проекте сосуществуют два слоя
дизайн-системы. Старый `ui-*` следует правилам движения довольно точно, а новый `shbz-*`,
который сейчас занимает бóльшую часть интерфейса (75 использований кнопок против 35),
не унаследовал ни отклика на нажатие, ни гейтинга hover, ни поддержки reduced-motion.
Все четыре плана — про то, чтобы подтянуть новый слой до стандарта старого.
