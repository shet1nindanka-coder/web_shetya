# Roadmap — v1 «Автономный milestone 2026-08-21»

**Milestone:** v1 — Условия в ручном создании, звонки родителям, статистика для разработчика
**Branch:** feat/autonomous-2026-08
**Mode:** autonomous (user unavailable; product decisions made by Claude, reported at the end)

## Phases

### Phase 1: Fix — условия задач при ручном создании занятия/ДЗ
**Status:** Not Started
**Goal:** Условия (conditionLatex) отображаются некорректно при ручном создании занятия или ДЗ — воспроизвести баг вживую (skill: run), исправить (skill: impeccable), проверить соседние экраны (skill: code-review).
**Success criteria:**
- Баг воспроизведён в живом приложении и зафиксирован (скриншот/описание)
- Условия отображаются корректно в ручном создании занятия и в ручной выдаче ДЗ
- Соседние экраны (ИИ-подбор, просмотр темы, кабинет ученика) не задеты

### Phase 2: Feature — напоминания о звонках родителям
**Status:** Not Started
**Goal:** Ежемесячные звонки родителям: напоминание от даты последнего состоявшегося звонка по каждому ученику; фиксация звонка с комментарием; история звонков; неудачная попытка не закрывает напоминание. Доступ: TEACHER + DEVELOPER, на уровне API. Отдельная вкладка/раздел в интерфейсе учителя.
**Success criteria:**
- UI-контракт до кода (gsd-ui-phase): состояния «пора звонить / просрочено / в этом месяце созвонились», пустое состояние
- Модель данных: история звонков (не перезапись), успешные и неудачные попытки
- Напоминание считается от последнего УСПЕШНОГО звонка per-student
- API-доступ только TEACHER/DEVELOPER (security-review), комментарии не попадают в логи
- UX-copy (design:ux-copy) для уведомлений и статусов
- code-review пройден

### Phase 3: Feature — статистика по учителям для роли «разработчик»
**Status:** Not Started
**Goal:** Информативная статистика по учителям: сколько выдано ДЗ, сколько учеников, сколько созвонов с родителями, сколько занятий и когда/на какие темы. Прочитать dataviz ДО кода графиков; компоновка — impeccable; code-review агрегатов (дубли, таймзоны).
**Success criteria:**
- dataviz skill прочитан до первой строки кода графиков
- Дашборд: ДЗ, ученики, созвоны (из данных фазы 2), занятия с датами и темами
- Агрегаты без дублей, таймзона Europe/Moscow учтена
- code-review пройден

## Order
Strict: 1 → 2 → 3 (фаза 3 использует данные звонков из фазы 2).
