> Визуально-интеракционный контракт раздела «звонки» (`/teacher/calls`, `/developer/calls`).
> Источник власти — инкумбентная дизайн-система ШБЗ (DESIGN.md + `app/globals.css`).
> Никаких новых библиотек, никакого shadcn, никаких новых цветов мимо токенов `--shbz-*`.

Accent reserved for: primary-кнопка формы, точка заголовка, рант нав-карточки, фокус полей. Больше нигде. Один градиентный элемент на блок («правило одного голоса»).

## Screens & Layout

### 1. Раздел `/teacher/calls` (rewrite `/developer/calls` уже существует)

Структура сверху вниз:

1. **`ShbzPageHeader`** — kicker: `Звонки`, title: `Звонки родителям`.
2. **Сводная строка** (только если есть ученики): счётчики текстом 13px muted:
   `Просрочено: N · Пора позвонить: N · Всего учеников: N`. Без чипов — цвет живёт в строках.
3. **Список учеников** — одна `.shbz-card px-7 py-2` со строками-разделителями
   `border-bottom: 1px solid var(--shbz-row-border)` (паттерн `students/page.tsx`).

**Строка ученика** (desktop, grid `md:grid-cols-[1.4fr_auto_auto]`, gap 20px, `py-5`):
- Колонка 1: имя ученика (16px/700 `--shbz-text-strong`, truncate); под ним мета-строка 13px `--shbz-text-muted` (последний звонок / попытка недозвона / «звонков ещё не было»); для DEVELOPER — вторая мета-строка `Учитель: {имя}` (13px `--shbz-text-soft`); если учитель удалён — `Учитель: —`.
- Колонка 2: статусный чип (см. Color).
- Колонка 3: действия — `shbz-btn-primary px-5 py-[11px] text-sm` «Записать звонок» + `shbz-btn-outline` «История (N)» (N = все записи, включая недозвоны; при N=0 кнопка не рендерится).

**Сортировка (locked):** просрочено → пора позвонить → недавно созвонились; внутри группы — по убыванию дней с якоря (самые давние сверху). Никаких пользовательских сортировок/фильтров в MVP.

**Раскрытие формы и истории** — inline-развёртка под строкой (не модалка): вложенная панель `--shbz-soft-bg`, радиус 12px, рамка-волосок, без тени («правило двух этажей»). Открыта максимум одна развёртка на строку; форма и история — две отдельные развёртки, открытие одной закрывает другую в той же строке.

### 2. Форма фиксации звонка (развёртка)

- **Исход** — сегмент-контрол `.shbz-seg` из двух кнопок: `Дозвонился` / `Не дозвонился`. Default: `Дозвонился`. Выбор обязателен (default покрывает).
- **Комментарий** — `.shbz-textarea` (min-height 96px), label 13px/600 `Комментарий`; поле необязательное.
- Подсказка с классом `.ui-hint` (13px `--shbz-text-soft`, скрывается при `data-hints="off"`): `Неудачная попытка сохранится в истории, но не сбросит отсчёт напоминания.`
- **Кнопки:** primary `Сохранить звонок` (в состоянии отправки — disabled + `Сохраняем…`), outline `Отмена` (закрывает развёртку, значения сбрасываются).
- После успеха: развёртка закрывается, строка и счётчики обновляются (router.refresh / повторный fetch), никаких тостов — обновлённый чип и мета-строка и есть подтверждение.
- Ошибка сети/сервера: inline `.shbz-notice-error px-5 py-4 text-sm` над кнопками внутри развёртки (см. Copywriting), форма не закрывается, введённое не теряется.

### 3. История звонков (развёртка)

Вертикальный список записей, новые сверху, разделители-волоски. Запись:
- Строка 1: дата+время 13px/600 `--shbz-text-strong` (Мск, формат «12 июля, 18:40») · исход: `Дозвонился` (600, `--shbz-text-strong`) или `Не дозвонился` (500, `--shbz-text-muted`).
- Строка 2 (если есть комментарий): body 15px/400, `white-space: pre-wrap`.
- Для DEVELOPER дополнительно: `— {имя учителя}` в строке 1 (13px `--shbz-text-soft`).
Никаких кнопок удаления/редактирования — история append-only.

### 4. Виджет на обзоре `/teacher` (и `/developer`)

Третья `ShbzNavCard`: kicker `Звонки`, title `Связь с родителями`, stats:
`{ label: "Пора позвонить", value }` + `{ label: "Просрочено", value }`, footer — существующая кнопка `Перейти` → `/teacher/calls`. Значения — чернильные цифры 23px/800 нав-карточки, без цветовой окраски.

### 5. Навигация

- `teacherItems` и `developerItems` в `dashboard-nav.tsx`: вкладка `{ href: "/teacher/calls" | "/developer/calls", label: "звонки" }` — строчными, ставится после «ученики» (teacher) / после «аккаунты» (developer). Match: `p.startsWith(...)`.
- Колокольчик уведомлений рендерится и для TEACHER/DEVELOPER (сейчас компонент гейтится `isStudent`) — тот же `StudentNotificationsBell`-паттерн, эндпоинт учителя из CONTEXT. Визуал колокольчика не меняется.

### 6. Мобильная вёрстка (< 768px)

- Строка ученика складывается в колонку (`flex flex-col gap-3`, как в `students/page.tsx`): имя+мета → чип → кнопки в `flex flex-wrap gap-2.5`.
- Шапка колонок (uppercase 11px) скрывается (`hidden md:grid`).
- Кнопки сохраняют высоту ≥ 40px (сенсорная цель), full-width не требуется.
- Развёртки работают так же; textarea не выходит за контейнер.

## Motion & Interaction

- Нажатия кнопок — системный отклик `scale(0.97)` за 60 мс (уже даёт `.shbz-btn-*`).
- Развёртки формы/истории — системная короткая анимация появления (150–200 мс), как у существующих раскрывающихся панелей; обязательный вариант под `@media (prefers-reduced-motion: reduce)` — без движения.
- Никакой бесконечной анимации в покое; спиннер — только на время отправки, если используется.
- Фокус — глобальное правило `:focus-visible` (мятная обводка 2px), ничего не переопределять.
- Чип статуса не анимируется при смене — обновление через перерисовку данных.
