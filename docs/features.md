# TutorFlow — функции сайта (с учётом созвона)

_Обновлено: 7 июля 2026._

**Легенда:** ✅ уже есть в приложении · 🟡 MVP к 1 августа (Сколково) · 🔵 позже / коммерция

> 🟡-пункты примерно соответствуют текущему списку задач (11 шт.). 🔵 — послеавгустовский roadmap. ✅ — то, что уже работает.

---

## 1. Доступ и роли
- ✅ Вход по email+пароль, сессии в куках, выход
- ✅ Две роли — учитель и ученик, редирект в свой раздел
- ✅ Смена имени и пароля
- 🟡 Онбординг ученика: при первом входе — входная диагностика
- 🔵 Роли для кураторов и родителей

## 2. Кабинет ученика
- ✅ Список тем → страница темы → страница задачи
- ✅ Светофор статуса по каждой задаче (зелёный/жёлтый/красный) + личные заметки
- ✅ Дедлайны: список и календарь
- ✅ Стрик, недельная активность, таймлайн прогресса
- 🟡 Решить судьбу жёлтого статуса (на созвоне обсуждали убрать)
- 🟡 Персональный план на урок — «что решать сегодня», выдаётся автоматически
- 🟡 Прохождение тестов (диагностика и тест в конце урока)
- 🔵 Загрузка фото решений

## 3. Кабинет учителя
- ✅ Темы: создание/редактирование/удаление, порядок, файлы теории и ДЗ (pdf/docx/png/jpg)
- ✅ LaTeX-условия и ответы по задачам, файлы-ответы
- ✅ Ученики: создание/удаление, карточка ученика
- ✅ Мониторинг прогресса по каждому ученику (доска статусов)
- ✅ Дедлайны по конкретному ученику и задаче
- ✅ Статистика с детализацией, таймлайн, поиск номера
- ✅ Выгрузка прогресса ученика в Excel
- 🟡 Режим урока (раздел 5)
- 🟡 Управление потоками/группами

## 4. Банк задач и методика (контент)
- ✅ Общие темы с нумерованными задачами (единые для всех учеников)
- 🟡 Иерархия тем: пререквизиты, порядок «от начала до конца» по уровню
- 🟡 Метаданные задач: сложность и оценка времени (для коротких самостоятельных)
- 🟡 Привязка темы к предмету и классу
- 🟡 Наполнение банка для 11 класса (математика)
- 🔵 Методички и модельные решения для самостоятельного разбора (пределы, параметры, эконом. задача, графики)
- 🔵 Лекции на поток: методические (единая технология решения) и мировоззренческие
- 🔵 Конвейер подготовки условий задач (оригинальные/переписанные)

## 5. Онлайн-урок (движок урока)
- 🟡 Старт урока: каждый ученик получает задание
- 🟡 Очередь для учителя — к кому и в каком порядке подходить (по времени захода/приоритету)
- 🟡 Учителю видны текущие задачи ученика и вопросы «на разбор»
- 🟡 Отметка «с кем уже поработал»
- 🟡 Выгрузка PDF с задачами ученика на занятие
- 🟡 Тест в конце урока: одной кнопкой всем, у каждого свой, ~15 минут
- 🟡 Отметка посещаемости прямо на уроке (раздел 7)

## 6. Диагностика, подбор и освоение
- 🟡 Входная диагностика → автоопределение уровня ученика
- 🟡 Адаптивный подбор задач по уровню и пробелам — «ИИ-ядро» продукта
- 🟡 Автопроверка теста → засчитывание освоения темы
- 🟡 Учёт пройденного/освоенного для следующего подбора
- 🔵 Более «умный» подбор (ML) на данных пилота

## 7. Дисциплина и посещаемость
- 🟡 Отметка присутствия/опоздания/отсутствия на уроке
- 🟡 Сводка посещаемости у учителя
- 🔵 Правила: договор с родителями, компенсация за пропуски, отчисление после N прогулов
- 🔵 Требования по посещаемости + уведомления

## 8. Честность / антисписывание (в основном позже)
- 🟡 (пилот) Правило: 1-й раз — предупреждение, 2-й — отчисление
- 🔵 Загрузка фото решений и проверка структуры решения
- 🔵 Детекция списывания с нейросетей

## 9. Предметы и потоки
- 🟡 Математика — основной продукт (выше готовность)
- 🟡 Потоки: сначала 11 класс, 10-й добираем позже
- 🔵 Информатика — второй продукт (пилот, с Петром)
- 🔵 Русский/история — по методологии, а не по баллам ЕГЭ
- 🔵 Массовый набор (сотни бесплатников), отбор лояльных преподавателей

## 10. Аналитика, отчёты, реалтайм
- ✅ Реалтайм-обновление дашбордов (SSE)
- ✅ Excel-выгрузка
- ✅ Рендер математики (KaTeX)
- 🟡 Демо-сценарий и отчёт для Сколково
- 🔵 Отчёты для родителей/кураторов

## 11. Упаковка для Сколково
- 🟡 Позиционирование: «система помощи учителю с ИИ» (не ГДЗ / не решебник / не учебник)
- 🟡 Два направления — математика и информатика — с разной степенью готовности
- 🟡 Рабочее демо хотя бы на одной группе
- 🟡 Короткая презентация под акселератор (запускается раз в месяц)

---

### Приоритеты на MVP (август)
Ядро для демо: **диагностика уровня → адаптивный подбор → режим урока (очередь + планы + PDF) → тест в конце → освоение темы**, плюс банк задач с иерархией и демо-данные по 11 классу.
