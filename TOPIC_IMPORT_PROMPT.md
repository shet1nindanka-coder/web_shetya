# Импорт темы из задачника

Как перенести задачник в TutorFlow, не набивая условия руками.

## Порядок действий

1. Откройте любой чат с ИИ, который умеет читать файлы (ChatGPT, Claude, Gemini — подойдёт любой).
2. Приложите файлы: PDF, скан, фото страниц, docx. Можно один файл с условиями, можно два — условия и отдельно ответы; модель разберётся сама.
3. Скопируйте промпт ниже целиком и отправьте вместе с файлом.
4. Модель пришлёт файл `.json` — скачайте его. Если она ответила текстом, скопируйте JSON целиком.
5. На сайте: откройте тему → **Редактировать** → блок «Импорт номеров из задачника»,
   загрузите файл, посмотрите предпросмотр, нажмите «Импортировать».

Предпросмотр показывает формулы отрисованными — если ИИ ошибся в разметке, это видно до записи
в базу, а не после.

## Что важно знать заранее

**Ответы.** Если в задачнике их нет, поле останется пустым. Автопроверка на таких номерах будет
ставить «нужна ручная проверка»: сравнивать ей не с чем. Есть отдельный ключ ответов — приложите
его тем же файлом или вторым.

**Сложность и время.** Промпт их не запрашивает. После импорта запустите штатную разметку
сложности из панели разработчика — она посчитает `difficulty` и `estimatedMinutes` по условиям.

**Картинки и чертежи.** Не переносятся. Задачи, которые без рисунка не решаются, ИИ пометит
в `warnings` — их придётся оформить руками или пропустить.

**Объём.** За один заход разумно брать до 200 задач. Больше — разбейте файл на части и
импортируйте в несколько приёмов, тема дополнится.

**Тема должна существовать.** Импорт наполняет уже созданную тему: сначала заведите её обычной
формой (название, описание, файлы теории и заданий), затем импортируйте номера. Удалять номера
импорт не умеет — только добавлять и заполнять.

## Промпт — копировать отсюда

```text
Ты — помощник по оцифровке задачников. Тебе дан один файл или два файла с задачами по математике. Извлеки задачи и верни ОДИН JSON-объект — больше ничего.

Сначала определи, что тебе дали. Возможны три случая, разбирайся сам, переспрашивать не нужно:
- ДВА ФАЙЛА: в одном условия задач, в другом ответы к ним. Сопоставь ответы с условиями по номерам задач;
- ОДИН ФАЙЛ с условиями и ответами сразу: ответы обычно идут отдельным разделом в конце, реже сразу после условия. Разбери такой файл на две части сам;
- ОДИН ФАЙЛ только с условиями. Тогда у всех задач answerLatex: null.

Что нужно сделать:
1. Найди пронумерованные задачи. Сохрани нумерацию источника: если задачи идут 101, 102, 103 или 301001, 301002 — так и пиши, не перенумеровывай с единицы.
2. Для каждой задачи запиши условие целиком, вместе со всеми пунктами а), б), в).
3. Ответы бери только из файлов. Сопоставляй по НОМЕРУ задачи, а не по порядку следования: в разделе ответов нумерация бывает с пропусками или идёт иначе. Если ответа нет или сопоставить уверенно не выходит — ставь null и добавь строку в warnings. НЕ РЕШАЙ задачи сам: придуманный ответ хуже отсутствующего.
4. Ничего не выдумывай. Если условие не читается или обрывается, всё равно включи задачу, запиши что удалось разобрать и добавь строку в warnings.

Разметка формул:
- Обычный текст пиши как есть, по-русски. В доллары оборачивай только математику, а не предложения целиком.
- Формула внутри строки — между одинарными долларами: Решите уравнение $x^2-5x+6=0$.
- Крупная отдельно стоящая формула — отдельный абзац целиком между двойными долларами: $$\int_0^1 x^2\,dx$$
- Абзацы разделяются пустой строкой.
- Пункты пиши подряд в одну строку, метками «а)», «б)», «в)»: а) $2^x=8$ б) $3^x=81$. Сайт сам разложит их по строкам, переносы здесь ставить не нужно.
- ПЕРЕНОСЫ СТРОК ИЗ ИСТОЧНИКА СОХРАНЯЙ. Если в задачнике условие записано в несколько строк — перечисление столбиком, таблица значений, несколько отдельных требований — ставь между ними \n. Пустая строка (\n\n) — новый абзац. Не склеивай многострочное условие в одну строку и не добавляй переносов, которых в источнике нет.
- Слова внутри формулы — через \text{}: $S_{\text{полн}}$.
- Дроби — \dfrac или \frac, корни — \sqrt, системы — \begin{cases}...\end{cases}.

Ограничения движка (сайт рендерит KaTeX, не полный LaTeX):
- Нельзя: \usepackage, \newcommand, \label, \ref, \includegraphics, окружения figure, table, tabular, align. Для выравнивания используй aligned внутри $$...$$.
- Если задача опирается на чертёж или картинку, которых нет в тексте, включи задачу и добавь строку в warnings: без рисунка она не решается.

КАК ЭКРАНИРОВАТЬ — самая частая ошибка, из-за неё файл не загружается:
Это JSON, поэтому каждый обратный слэш внутри строки должен быть удвоен. Одиночных обратных слэшей в файле быть не должно ни одного — проверь это отдельным проходом перед отправкой.
Правильно:   "conditionLatex": "Решите $\\dfrac{1}{2\\sin x}=1$."
Неправильно: "conditionLatex": "Решите $\dfrac{1}{2\sin x}=1$."

КАК ОТДАТЬ ОТВЕТ:
Пришли результат ОДНИМ ФАЙЛОМ с расширением .json и ничего не пиши в чате: ни пояснений, ни комментариев, ни markdown-обёртки ```json. Если приложить файл нельзя, выведи в чат только сам JSON-объект, начиная с { и заканчивая }.

Содержимое файла — строго один JSON-объект такого вида:

{
  "formatVersion": 1,
  "topic": {
    "title": "Логарифмические уравнения",
    "description": "Простейшие логарифмические уравнения и уравнения, сводящиеся к ним."
  },
  "numbers": [
    { "number": 1, "conditionLatex": "Решите уравнение $\\log_2(x+1)=3$.", "answerLatex": "$x=7$" },
    { "number": 2, "conditionLatex": "а) $\\lg x=2$ б) $\\ln x=1$", "answerLatex": "а) $x=100$ б) $x=e$" },
    { "number": 3, "conditionLatex": "Найдите область определения функции $y=\\log_5(x-2)$.", "answerLatex": null }
  ],
  "warnings": ["Номер 14: часть условия не читается на скане"]
}

Правила заполнения полей:
- title — короткое название темы, до 200 символов. Если в файле есть заголовок раздела, возьми его.
- description — 1-2 предложения о содержании темы, до 1000 символов. Необязательное: если брать нечего, поставь пустую строку.
- number — целое положительное число, ровно как в задачнике; длинные коды вроде 301001 допустимы. Каждый номер встречается один раз.
- conditionLatex — обязательно, непустое.
- answerLatex — строка или null.
- warnings — список строк; если всё чисто, пустой список.

Перед отправкой перечитай файл и проверь три вещи: это валидный JSON, все обратные слэши удвоены, номера не повторяются.
```

## Схема файла (для справки)

| Поле | Тип | Обязательно | Ограничение |
|---|---|---|---|
| `formatVersion` | число | да | сейчас `1` |
| `topic.title` | строка | да | до 200 символов |
| `topic.description` | строка | нет | до 1000 символов |
| `numbers[].number` | целое | да | 1…9999, без повторов |
| `numbers[].conditionLatex` | строка | да | до 4000 символов |
| `numbers[].answerLatex` | строка или null | нет | до 2000 символов |
| `warnings[]` | массив строк | нет | показывается при импорте |

Импортёр не доверяет файлу: проверяет структуру, отсекает лишние поля, отлавливает повторы
номеров и невалидные формулы. Всё, что не прошло проверку, показывается в предпросмотре
списком — до записи в базу.
